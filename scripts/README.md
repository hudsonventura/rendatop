# Bank Logos

SVG bank logos keyed by Brazilian bank code.

- Main source: `https://github.com/Tgentil/Bancos-em-SVG`.
- When the repository had a version without the bank name, that variant was preferred.
- `140.svg`, `260.svg`, and `386.svg` intentionally reuse the Nubank asset because they belong to the same group.
- `121.svg` and `623.svg` remain custom fallbacks because Agibank and PAN were not present in the source repository on June 1, 2026.
